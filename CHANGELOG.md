# Changelog

All notable changes to **ByteBell** are documented here.
This project follows [Semantic Versioning](https://semver.org/).

## [1.1.0] — 2026-09-29

- New app logo in the AkihiroLabs family style (navy base, white symbol, amber accent): `app-icon.png`, `favicon.png`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`.
- Home-screen / install icon is now the ByteBell bell. Byte 🦝 (`icon.png`) is still used inside the app and for notifications.
- Service worker cache bumped to `bytebell-v2` so installed apps pick up the new icon.

## [1.0.0] — 2026-09-28

- Added `README.md` and `CHANGELOG.md`.
- Current features: weekly timetable, Today/Week views, presets, overnight blocks, Web Push reminders, optional Supabase sync, installable PWA, EN/JA/MY.
